动画编辑器

时间轴关键帧编辑 clip / 状态动画，真引擎（grok-player 移植）实时预览， 播放头与 clip 时间轴严格对齐。

双击 轨道空白加关键帧 · ⌘+滚轮 缩放时间轴 · ←→ 微调（Shift 加速）· ⌘C/⌘V 复制粘贴 · Delete 删除 · Esc 取消选择 · ⌘Z 撤销 · ⌘⇧Z 重做

t = 0.00s 100%

预览跑的是原版引擎移植（grok-player），播放头与 clip 时间轴严格对齐 （firstPhase = 0）。拖下方时间轴的播放头可以逐帧 scrub（引擎 frozenAt 确定性模式）。

单击空白取消选择；双击轨道空白添加关键帧；空白处拖动 = 框选； Shift+点菱形加选/减选；拖菱形改时刻（吸附 0.05s 网格与其他关键帧，⌘ 临时关闭， 多选整体平移）；⌘+滚轮缩放时间轴；←/→ 微调（Shift 加速）；⌘C/⌘V 复制粘贴； Delete 删除；Esc 取消选择；⌘Z 撤销、⌘⇧Z 重做。

导出 / 导入

导出的 clip JSON 与原引擎数据同构：放进 grok-recipes.json 的 clips 数组、把名字加进某个状态的 clips 池即可被引擎播放。 「从文本框载入」接受 {clip, state} 或单个 clip 对象。
